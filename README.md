# ノーサンキュー！ オンライン版

それぞれのスマホから参加できるオンライン対戦版です（オフライン版：`/workspace/geschenk/index.html`）。

## 遊び方
1. ホストが「部屋を作る」→ 4文字の部屋コード・招待URL・QRコードが表示されます。
2. 参加者は招待URL（またはQR）を開くか、コードを入力して「部屋に入る」。
3. ホストは人数が足りなければ「ふーさん🐻」（CPU）を追加し、回戦数（1〜5）を選んで「ゲーム開始」。
4. ホストはゲーム中、画面を開いたままにしてください（ホストの端末がゲームを進行します）。

## 構成
- 静的ファイルのみ：`index.html` / `app.js` / `logic.js` / `config.js` / `vendor/peerjs.min.js`（PeerJS 1.5.5, MIT, 同梱）/ `vendor/qrcode.js`（qrcode-generator, MIT, 同梱）
- 通信：WebRTC P2P（PeerJS）。シグナリングは PeerJS 公式の無料クラウド（0.peerjs.com）。
- ホストのブラウザが唯一の正（山札・全員のチップ・CPUの判断を管理）。各プレイヤーには自分に見せてよい情報だけを送信。
- 切断対策：同じニックネーム（または同じブラウザ）で入り直すと元の席に復帰。ホストは切断者を「ふーさん🐻」に交代可能（本人が戻ると自動で席を返却）。ホストがページを再読み込みしても「前回の部屋を再開する」で続行可能。

## 設定（config.js）
- `iceServers`：STUN/TURN。モバイル回線同士で接続できない場合は TURN サーバー（Cloudflare / Metered など、要アカウント）を追加。
- `peer`：自前の PeerJS サーバーを使う場合に指定。

## テスト（test/）
- `logic.test.js`：ゲームロジック（3000ゲーム＋400マッチのシミュレーション）
- `e2e-online.js`：ホスト＋参加者2人＋ふーさん🐻で2回戦を実UI・実シグナリングでプレイ（切断・復帰・CPU交代・チップ秘匿の監査を含む）
- `e2e-host-resume.js`：ホストの再読み込み→部屋の再開
- `stun-server.js`：テスト専用の最小STUN応答サーバー（テスト環境はUDPの外向き通信が遮断されているため）
